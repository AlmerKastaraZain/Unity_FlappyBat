## About The Project

FlappyBad is a simple and fun arcade-style game inspired by the classic Flappy Bird. Players control a bat, attempting to fly between rows of oncoming pipes without hitting them. Tap to make the bat flap upwards! This game is developed using the Unity game engine.

## Prerequisites

This section lists the necessary hardware and software to run and develop FlappyBad.

### Hardware Requirement

*   **Operating System**: Windows 7 (SP1+), 8, 10, 11 / macOS 10.13+ / Linux (Ubuntu 18.04+, CentOS 7+)
*   **Processor**: Dual Core 2.0 GHz or higher
*   **RAM**: 4GB or more
*   **Graphics Card**: Graphics card with DX10 (shader model 4.0) capabilities.

### Software Requirement

*   [Unity Hub](https://unity.com/download)
*   [Unity Editor (e.g., 2021.3 LTS or the version specified in ProjectVersion.txt)](https://unity.com/releases/editor/archive)
*   A code editor like [Visual Studio](https://visualstudio.microsoft.com/) or [Visual Studio Code](https://code.visualstudio.com/) (often integrated with Unity installation).

<p align="right">(<a href="#readme-top">back to top</a>)</p>

### Installation

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/AlmerKastaraZain/Unity_FlappyBat.git
    ```
    Or download the ZIP file and extract it.
2.  **Open in Unity Hub:**
    *   Launch Unity Hub.
    *   Click on "Projects" on the left sidebar.
    *   Click the "Open" button (or "Add project from disk").
    *   Navigate to the directory where you cloned or extracted `Unity_FlappyBat` and select the project folder.
3.  **Open Project in Unity Editor:**
    *   Unity Hub will list the project. Click on it to open it in the Unity Editor.
    *   If you don't have the required Unity Editor version, Unity Hub will prompt you to install it.

<p align="right">(<a href="#readme-top">back to top</a>)</p>

### Running The Game

1.  **Open the Main Scene:**
    *   In the Unity Editor, navigate to the `Project` window (usually at the bottom).
    *   Find the main game scene, typically located in an `Assets/Scenes/` folder (e.g., `GameScene.unity` or `MainMenu.unity`).
    *   Double-click the scene file to open it.
2.  **Play in Editor:**
    *   Press the "Play" button (►) located at the top-center of the Unity Editor interface.
    *   The game will start running within the editor.

**Building an Executable (Optional):**
1.  Go to `File > Build Settings...` in the Unity Editor.
2.  Select your target platform (e.g., Windows, macOS, Linux).
3.  If the platform is not the current one, click "Switch Platform".
4.  Add open scenes to the build by clicking "Add Open Scenes". Ensure the main scene is at index 0 or is the first one loaded.
5.  Click "Build" and choose a location to save the game executable.
6.  Once the build is complete, navigate to the chosen location and run the generated executable file.
